# NoxVote brand assets

The production identity follows the accepted ORBIT direction in
`.thoughts/design/2026-08-01-orbit-direction.md`.

## Production files

- `noxvote-mark.svg` — canonical editable orbit mark.
- `noxvote-mark.png` — 512 × 512 transparent raster export.

The same mark is already used by the landing, app, and docs favicons. Keep its geometry intact: one
ink ring and one ember satellite.

## Visual tokens

- Paper: `#f2efe7`
- Ink: `#141413`
- Ember: `#c04a1e`
- Display: Sofia Sans
- Evidence and technical labels: JetBrains Mono

## Concept board

`noxvote-brandkit-overview.png` is a generative review board used to pressure-test the destination
idea across a lockup, banner, thumbnail, favicon, and proof card. It is not production copy authority:
small labels and URLs inside it are illustrative. The deterministic launch assets in `../launch/`
are the shippable outputs.
