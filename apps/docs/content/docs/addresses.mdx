deployment checkpoint is published. Until then, no NoxVote contract should be assumed live,

## Local development profile

The complete stack runs locally against the released Nox Docker images — this is the same
environment the [quick start](/docs/quickstart) uses and the judged demo's fallback:

```bash
pnpm test:integration   # boots Handle Gateway, KMS, ingestor, JetStream, Runner
```

The Hardhat Nox plugin manages the containers; contracts deploy fresh each run, so the local
profile needs no address table.
